## Escopo
### Inclui — mínimo de 6 telas distintas
1. Login / cadastro
2. Home / lista de projetos (Gerente) ou minhas tarefas (Colaborador)
3. Detalhe do projeto
4. Formulário de projeto (criar/editar)
5. Lista / detalhe de tarefa
6. Dashboard (visão consolidada)
7. (desejável) Perfil / configurações
### Não inclui
- Código Compose (issues do Ciclo 1)

## Critérios de aceite
- [ ] Fluxo Gerente e fluxo Colaborador navegáveis de ponta a ponta
- [ ] Estados vazios e de erro esboçados em pelo menos 2 telas — R10/R11
- [ ] Contraste e áreas de toque justificados no memorial — R11
- [ ] Link do protótipo no README ou em `prototipos/`
- [ ] Apresentável no Checkpoint 1 sem depender de build
