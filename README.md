# GerenciaDeProjetosApp

Aplicativo mobile para gerenciamento simples de projetos, com app Android nativo e backend em Python.

## Estrutura do Projeto

```
GerenciaDeProjetosApp/
├── android/          # App mobile (Android Studio / Kotlin)
├── backend/          # API backend (Python)
└── prototipos/       # Protótipos de telas e fluxos
```

## Stack

- **Mobile**: Android (Android Studio)
- **Backend**: Python
- **Versionamento**: Git + GitHub

## Status do Projeto

🚧 **Em fase de prototipação** — o desenvolvimento iniciará após a definição dos protótipos.
